After installation, open a job position (HR → Configuration →
Job Positions) and select the DK 003:2010 classification from the
dropdown next to the department field.

**Filtering and grouping in the job list:**

* Use the *Job Classification* field in the search bar to find
  jobs by their classification code or name.
* Use the *Group By → Job Classification* filter to see how many
  positions your company has in each classification bucket —
  useful for state statistical reports.

**Note on new classifications:** the dropdown does not allow
creating new classifications on the fly. DK 003:2010 is an
official state standard; if a classification is missing, add it
through the classifier module directly, not through the job form.
